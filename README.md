# PDF Generator

🚀 **PDF Generator - автоматизированная система создания профессиональных счетов-фактур**

Создам для вас индивидуальную систему генерации PDF документов из ваших CSV/JSON данных с использованием гибких HTML шаблонов. Система включает интерактивное меню выбора файлов, автоматическую подстановку данных и мгновенное создание PDF с поддержкой кириллицы.

Идеально подойдет бухгалтерам, менеджерам по продажам и предпринимателям, кто работает с большим количеством счетов и нуждается в быстрой генерации профессиональных документов.

Преимущество: экономьте часы ручной работы - процесс занимает считанные секунды, документы выглядят профессионально, система кроссплатформенная и не требует специальных навыков.

## Требования

- Python 3.8+
- Windows, macOS или Linux

## Установка

1. Активируйте виртуальное окружение:
   ```bash
   # На Windows
   venv\Scripts\activate

   # На macOS/Linux
   source venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```


## Использование

1. Поместите файлы данных (CSV/JSON) в директорию `data/`
2. Поместите HTML шаблоны в директорию `templates/`
3. Запустите скрипт одним из способов:

   **На Windows:**
   ```cmd
   run_pdf_generator.bat
   ```
   или вручную:
   ```cmd
   venv\Scripts\activate
   python pdf_generator.py
   ```

   **На macOS/Linux:**
   ```bash
   ./run_pdf_generator.sh
   ```
   или вручную:
   ```bash
   source venv/bin/activate
   python pdf_generator.py
   ```

4. Следуйте инструкциям в консоли:
   - Выберите файл данных
   - Выберите HTML шаблон
   - Выберите invoice ID
   - PDF будет автоматически сгенерирован и открыт

## Формат данных

### CSV файлы
Должны содержать колонку `invoice_id` или `id` для идентификации счетов.

**Обязательные поля:**
- `invoice_id` или `id` - идентификатор счета
- `date` - дата счета
- `customer_name` - имя клиента
- `customer_address` - адрес клиента
- `product_name` - наименование товара
- `quantity` - количество
- `price` - цена за единицу
- `total` - общая сумма

**Опциональные поля для персонализации:**
- `description` - описание товара
- `director_power_attorney_number` - номер доверенности директора
- `director_power_attorney_date` - дата доверенности директора
- `accountant_power_attorney_number` - номер доверенности главного бухгалтера
- `accountant_power_attorney_date` - дата доверенности главного бухгалтера
- `company_logo` - имя файла логотипа (без расширения, файл должен быть в папке logos/)

### JSON файлы
Могут содержать:
- Массив объектов с данными счетов
- Объект с ключом `data`, содержащим массив счетов

**Структура объекта счета аналогична CSV полям.**

## HTML шаблоны

Шаблоны используют синтаксис Jinja2. Доступные переменные соответствуют колонкам в файлах данных.

Пример простого шаблона:
```html
<h1>Счет № {{ invoice_id }}</h1>
<p>Клиент: {{ customer_name }}</p>
<p>Сумма: {{ total }} руб.</p>
```

## Логотипы компаний

Поместите файлы логотипов в папку `logos/` в форматах PNG, JPG, JPEG, GIF или SVG.

**Система автоматически:**
- Предлагает выбрать логотип из доступных файлов при генерации PDF
- Находит файл с подходящим расширением по имени из данных
- Отображает логотип в PDF в формате A4

**Примеры имен файлов:**
- `technoservice_logo.png`
- `mycompany.jpg`
- `logo.gif`

**В данных укажите:**
- `company_logo`: имя файла без расширения (опционально, будет предложен выбор из доступных)

## Особенности

- Поддержка кириллицы (используется шрифт DejaVu Sans)
- Автоматическое открытие PDF после генерации
- Кроссплатформенная работа (Windows/macOS/Linux)
- Обработка ошибок и валидация данных
- Поддержка логотипов компаний с интерактивным выбором
- Персонализация номеров и дат доверенностей
- Формат PDF: A4 с оптимизированными отступами
- Чистый вывод без системных предупреждений (GLib подавлены)
- Умная обработка заблокированных файлов с автоматическим созданием уникальных имен
