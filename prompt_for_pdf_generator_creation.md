# Промпт для создания приложения PDF Generator

## Основная задача
Создать полнофункциональное Python-приложение для генерации PDF-документов из CSV/JSON данных с использованием HTML-шаблонов. Приложение должно быть готово к использованию, протестировано и загружено на GitHub.

## Основные требования

### 1. Функциональность приложения
Приложение должно выполнять следующие функции:
- Чтение CSV и JSON файлов из директории `/data`
- Чтение HTML-шаблонов из директории `/templates`
- Интерактивное меню для выбора файлов данных и шаблонов
- Вывод списка доступных invoice ID из выбранного файла данных
- Выбор конкретного invoice ID для генерации PDF
- Генерация PDF с подстановкой данных в HTML-шаблон
- Автоматическое открытие PDF в системной программе просмотра
- Поддержка кириллицы с использованием шрифта DejaVu Sans

### 2. Дополнительные возможности
- **Выбор логотипов:** Интерактивный выбор логотипов из папки `/logos` с автоматическим поиском файлов PNG/JPG/JPEG/GIF/SVG
- **Формат A4:** Все PDF генерируются в формате A4 с оптимизированными отступами
- **Доверенности:** Данные о номерах и датах доверенностей директора и главного бухгалтера загружаются из исходных файлов
- **Обработка ошибок:** Умная обработка ошибок доступа к файлам с автоматическим созданием уникальных имен
- **Чистый вывод:** Подавление системных предупреждений GLib для Windows

### 3. Структура проекта
```
PDFGenerator/
├── data/                    # CSV и JSON файлы с данными
├── templates/              # HTML шаблоны
├── logos/                  # Логотипы компаний (PNG, JPG, JPEG, GIF, SVG)
├── output/                 # Сгенерированные PDF (исключается из git)
├── pdf_generator.py        # Основное приложение
├── requirements.txt        # Зависимости Python

├── test_pdf.py            # Тестовый скрипт
├── .gitignore             # Исключения для git
```


### 2. pdf_generator.py
Основной файл приложения должен содержать:

#### Класс PDFGenerator:
- `__init__()`: Инициализация с настройками CSS для A4, подавлением GLib предупреждений
- `get_data_files()`: Получение списка CSV/JSON файлов
- `get_template_files()`: Получение списка HTML шаблонов
- `load_data_file()`: Загрузка данных из CSV (pandas) или JSON (json)
- `load_template()`: Загрузка HTML шаблона
- `get_invoice_ids()`: Получение списка invoice ID
- `get_invoice_data()`: Получение данных для конкретного invoice
- `process_logo_path()`: Обработка пути к логотипу с поиском по расширениям
- `get_available_logos()`: Получение списка доступных логотипов
- `select_logo()`: Интерактивный выбор логотипа
- `generate_pdf()`: Генерация PDF с обработкой ошибок доступа к файлам
- `open_pdf()`: Открытие PDF в системной программе
- `print_menu()`: Вывод меню выбора
- `run()`: Основной цикл программы

#### CSS настройки:
```css
@page {
    size: A4;
    margin: 2cm;
}
@font-face {
    font-family: 'DejaVu Sans';

    font-family: 'DejaVu Sans', 'Arial', sans-serif;

}
```

### 6. Скрипты запуска

#### run_pdf_generator.bat (Windows):
```batch
@echo off
call venv\Scripts\activate.bat
set GIO_USE_VFS=local
set GIO_MODULE_DIR=
python pdf_generator.py 2>nul
pause
```

```bash

source venv/bin/activate

export GIO_MODULE_DIR=
```

## Шаги создания приложения

### Шаг 1: Настройка проекта
1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать: `venv\Scripts\activate` (Windows) или `source venv/bin/activate` (Linux/Mac)
3. Установить зависимости: `pip install -r requirements.txt`
4. Создать структуру директорий: `data/`, `templates/`, `logos/`, `output/`

### Шаг 2: Создание основного кода
1. Реализовать класс PDFGenerator с всеми методами
2. Добавить обработку логотипов и доверенностей
3. Реализовать умную обработку ошибок доступа к файлам
4. Добавить подавление GLib предупреждений

### Шаг 3: Создание шаблонов
1. Создать invoice_template.html с полным набором полей
2. Создать simple_invoice.html с упрощенным видом
3. Добавить поддержку динамических логотипов и доверенностей

### Шаг 4: Тестовые данные и файлы
1. Создать CSV и JSON файлы с тестовыми данными
2. Сгенерировать тестовые логотипы
3. Создать скрипты запуска

### Шаг 5: Тестирование
1. Запустить тестовый скрипт: `python test_pdf.py`
2. Протестировать основной функционал
3. Проверить обработку ошибок доступа к файлам
4. Убедиться в корректности генерации PDF в формате A4

### Шаг 6: Документация и GitHub
1. Создать подробный README.md с оффером
2. Инициализировать git репозиторий
3. Создать .gitignore
4. Добавить все файлы и создать коммит
5. Загрузить на GitHub
