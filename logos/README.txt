Папка для логотипов компаний

Поместите сюда файлы логотипов в форматах:
- PNG (.png)
- JPG/JPEG (.jpg, .jpeg)
- GIF (.gif)
- SVG (.svg)

Примеры имен файлов:
- technoservice_logo.png
- mycompany.jpg
- logo.gif

В CSV/JSON данных укажите имя файла без расширения в поле company_logo.
Система автоматически подберет файл с подходящим расширением.

Пример:
company_logo: technoservice_logo
Файлы для поиска: technoservice_logo.png, technoservice_logo.jpg, etc.
